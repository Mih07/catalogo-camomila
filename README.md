🌿 Catálogo Virtual Camomila Sabonetes
Este é um catálogo interativo desenvolvido para a Camomila Sabonetes e Cosméticos Artesanais. O projeto foi criado para facilitar o trabalho das revendedoras, permitindo que elas apresentem os produtos de forma profissional e recebam pedidos organizados diretamente no WhatsApp.

✨ Funcionalidades
Acesso Restrito: Sistema de login por código exclusivo para revendedoras.

Catálogo Dinâmico: Sincronização em tempo real com o Airtable para gestão de estoque, preços e descrições.

Filtros Inteligentes: Navegação por categorias (Relaxantes, Energizantes, Kits, etc.).

Carrinho de Compras: Interface amigável para seleção de produtos com reset automático após a finalização.

Fechamento via WhatsApp: Envio de pedido formatado com nome do cliente, itens e forma de pagamento para a revendedora correta (via parâmetro ref).

Design Responsivo: Otimizado para visualização perfeita em celulares e computadores.

🛠️ Tecnologias Utilizadas
HTML5 / CSS3 (com animações personalizadas).

Bootstrap 5 (Layout e Modais).

JavaScript (ES6+) (Lógica do carrinho e consumo de API).

Airtable API (Banco de dados dinâmico).

Google Analytics (Monitoramento de tráfego).

🚀 Como funciona o fluxo
A revendedora acessa o link personalizado (ex: ?ref=NOME2026).
Link oficial: https://seusitesuacara.com/camomila/
O sistema identifica a revendedora e libera o catálogo.

O cliente monta o pedido e finaliza.

A mensagem é disparada para o WhatsApp da revendedora com todos os detalhes organizados.
